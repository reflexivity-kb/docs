# 用蒙特卡羅評估S&P 500下跌5%時的組合風險

[← 按資產類別瀏覽](../README.md) · [所有使用案例](../../README.md)

**適用使用者：** 多資產基金經理、組合風險經理、對沖基金  
**資產類別：** 多資產、美股、外匯  
**研究觀察期間：** 2023年10月至2026年10月估計樣本

> 圖表與數值反映指定時期的研究示例，不代表即時市場報價或投資建議。

**[在Reflexivity開啟研究示例（英文）→](https://app.reflexivity.com/alfred?mode=research&conversationId=e2b98809-14cb-44d8-8889-b0a4820fdaf1&scrollTo=top)**

## 使用的提問

> [!IMPORTANT]
> 假設我的組合持有NVDA、AAPL、MSFT、GOOGL、AMZN、META、AVGO、TSLA、BRK.B、LLY、JPM、V、MA、WMT、COST、XOM、NFLX、AMD、BAC、UNH、USDJPY、EURUSD及GBPUSD，所有資產等權。請用蒙特卡羅方法評估S&P 500下跌5%時的下行風險。

## 由持股清單建立條件式壓力測試

投資組合含**20檔美股及3組外匯貨幣對**，共23個等權重持倉，每項約 **4.35%**。假設S&P 500下跌 **5%**，根據歷史Beta與殘差相關性進行 **50,000次**模擬。

## 模擬回報分位數

![SP500下跌5百分比條件下的投資組合模擬回報分位數](../../../../assets/usecases/reflexivity/deep-research-2026-10/RX-USECASE-0082-simulated-portfolio-quantiles.png)

*圖2：模擬回報的分位數柱狀圖，不是直方圖或連續概率密度。*

| 指標 | 模擬結果 |
| --- | ---: |
| 平均組合回報 | −4.66% |
| 組合SPX Beta | 0.93 |
| 95% VaR回報門檻 | −5.16% |
| 99% VaR回報門檻 | −5.37% |
| 損失超過5%的概率 | 13.4% |

以上數值仰賴**固定Beta與近似常態分布殘差**的假設，不能保證實際市場跌幅上限。尾部衝擊、流動性風險及相關性突變可能造成更嚴重損失。股票與外匯貨幣對等權時，還須明確定義名目金額、報價方向及損益換算方式。
