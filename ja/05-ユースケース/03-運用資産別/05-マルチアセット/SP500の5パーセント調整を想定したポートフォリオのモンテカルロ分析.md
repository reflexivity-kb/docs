# S&P 500の5%調整を想定したポートフォリオのモンテカルロ分析

[← 運用資産別](../README.md) · [ユースケース一覧](../../README.md)

**対象ユーザー：** マルチアセット運用者、ポートフォリオリスク管理者  
**主な資産：** マルチアセット、米国株、為替  
**調査の対象期間：** 2023年10月～2026年10月の推定期間

> 数値や市場状況は該当期間の研究例であり、最新の市況や投資推奨ではありません。

**[Reflexivityで調査例を開く →](https://app.reflexivity.com/alfred?mode=research&conversationId=4a8bfd1e-951f-4b13-9184-ea44acc7affc&scrollTo=top)**

## 使用したプロンプト

> [!IMPORTANT]
> S&P 500が5%調整した場合、NVDA、AAPL、MSFT、GOOGL、AMZN、META、AVGO、TSLA、BRK.B、LLY、JPM、V、MA、WMT、COST、XOM、NFLX、AMD、BAC、UNH、USDJPY、EURUSD、GBPUSDのポートフォリオの下落リスクをモンテカルロ分析で評価してください。すべての資産を等ウェイトと仮定します。

## 実際の保有リストからストレス分布を試算する

米国株 **20銘柄**と為替ペア **3つ**の計23ポジションを等ウェイト（各約 **4.35%**）とします。S&P 500が **5%下落**する条件で、過去の市場ベータと残差相関を使った **50,000回**のモンテカルロ試算を行います。

## 条件付きリターン分布の分位点

![SP500が5%下落した条件でのモンテカルロ試算分位点](../../../../assets/usecases/reflexivity/deep-research-2026-10/RX-USECASE-0082-simulated-portfolio-quantiles.png)

*図2：シミュレーション結果のリターン分位点です。ヒストグラムや滑らかな確率密度曲線ではありません。*

| 指標 | 試算結果 |
| --- | ---: |
| 平均ポートフォリオリターン | −4.66% |
| SPXベータ | 0.93 |
| 95% VaRのリターン閾値 | −5.16% |
| 99% VaRのリターン閾値 | −5.37% |
| 5%超の損失確率 | 13.4% |

これは**一定のベータとほぼ正規分布の残差**を仮定した条件付き結果であり、将来の最大損失を保証しません。相関急変、流動性ショック、非線形損失は十分に反映されません。株式とFXペアを同じ数値ウェイトで扱う場合は建玉の名目額、通貨換算、損益方向を明確にしてください。
