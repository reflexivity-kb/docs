# Microsoft 365 CopilotとTeamsでReflexivityを有効にするには？

[← FAQ](README.md) · [← 利用ガイド](../02-利用ガイド/README.md)

Microsoft 365 Copilotでは、現在のReflexivity案内上、アクティブなReflexivity契約と利用可能なMicrosoft 365 Copilot環境が必要です。既存のお客様はReflexivityのアカウント設定から連携を有効にし、Copilot側で認証できます。Teamsでは、「アプリ」でReflexivityを検索し、Reflexivityアカウントでサインインして、Alfredを対象のチャットやチャネルにピン留めします。組織によっては管理者承認が必要です。
