For Microsoft 365 Copilot, Reflexivity currently states that the integration operates within existing Microsoft 365 Copilot security and permission boundaries and that Reflexivity is SOC 2 compliant. For the Microsoft 365 source connections documented in June 2026, users choose which supported sources Alfred can access and can disconnect them. Organization-level administrator approval may still be required.
