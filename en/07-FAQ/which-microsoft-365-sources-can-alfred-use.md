# Which Microsoft 365 Sources Can Alfred Use?

Alfred can use three Microsoft 365 source families: SharePoint & OneDrive files and folders, Outlook email messages, and OneNote notebooks and pages. Alfred accesses only sources the user chooses to connect, and a connected source can be disconnected. Actual availability can depend on the Reflexivity account, Microsoft 365 tenant, and administrator policy.
