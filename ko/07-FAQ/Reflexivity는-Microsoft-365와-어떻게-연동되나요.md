# Reflexivity는 Microsoft 365와 어떻게 연동되나요?

[← FAQ](README.md) · [← 이용 가이드](../02-이용가이드/README.md)

Reflexivity는 투자팀이 이미 사용하는 Microsoft 365 업무 흐름에 투자 인텔리전스를 더합니다. SharePoint/OneDrive·Outlook·OneNote에서 선택한 소스를 Alfred에 연결하고, Microsoft Teams에서 Alfred를 사용하며, Microsoft 365 Copilot 안에서 Reflexivity Knowledge Graph를 활용하는 세 가지 방식을 연결해 사용할 수 있습니다.
