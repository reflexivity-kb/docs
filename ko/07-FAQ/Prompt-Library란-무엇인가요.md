# Prompt Library란 무엇인가요?

[← FAQ](README.md) · [2026년 7월 제품 로드맵](https://github.com/reflexivity-kb/platform/blob/main/ko/04-릴리스/2026-07-제품-로드맵.md)

Prompt Library는 자주 사용하는 분석을 재사용 가능한 템플릿으로 저장하기 위한 기능입니다. 저장한 워크플로는 분석을 처음부터 다시 만들지 않고 대상 기업만 바꿔 다시 사용할 수 있습니다.

**2026년 7월 로드맵**에서는 연말 로드맵 항목이었고, **2026년 8월 제품 업데이트**에서는 ‘출시 준비 중’으로 표시되었습니다. 이는 당시의 계획 상태이며 현재 제공을 보장하지 않습니다.

[2026년 7월 제품 로드맵](https://github.com/reflexivity-kb/platform/blob/main/ko/04-릴리스/2026-07-제품-로드맵.md)과 [2026년 8월 제품 업데이트 스냅샷](https://github.com/reflexivity-kb/platform/blob/main/ko/04-릴리스/2026-08-제품-업데이트-스냅샷.md)도 확인해 주세요.

현재 제공 상태나 이용 권한은 **jim@reflexivity.com**으로 문의해 주세요.
