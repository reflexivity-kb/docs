# Microsoft 365 Copilot과 Teams에서 Reflexivity를 활성화하려면 어떻게 하나요?

[← FAQ](README.md) · [← 이용 가이드](../02-이용가이드/README.md)

Microsoft 365 Copilot을 사용하려면 현재 Reflexivity 안내상 활성 Reflexivity 구독과 이용 가능한 Microsoft 365 Copilot 환경이 필요합니다. 기존 고객은 Reflexivity 계정 설정에서 연동을 활성화하고 Copilot에서 인증할 수 있습니다. Teams에서는 Apps에서 Reflexivity를 검색하고 계정에 로그인한 뒤 Alfred를 필요한 채팅이나 채널에 고정합니다. 일부 조직에서는 Microsoft 365 관리자 승인이 필요합니다.
