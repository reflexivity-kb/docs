# 用蒙特卡洛模拟评估S&P 500下跌5%时的组合风险

[← 按资产类别浏览](../README.md) · [全部使用案例](../../README.md)

**适用用户：** 多资产投资经理、风险经理、对冲基金  
**资产类别：** 多资产、美国股票、外汇  
**研究观察期：** 2023年10月至2026年10月估计样本

> 下列价格、估计和情景为指定时期的研究演示，不代表实时行情或投资建议。

**[在Reflexivity中打开研究示例（英文）→](https://app.reflexivity.com/alfred?mode=research&conversationId=e2b98809-14cb-44d8-8889-b0a4820fdaf1&scrollTo=top)**

## 使用的提示词

> [!IMPORTANT]
> 假设我的投资组合包括NVDA、AAPL、MSFT、GOOGL、AMZN、META、AVGO、TSLA、BRK.B、LLY、JPM、V、MA、WMT、COST、XOM、NFLX、AMD、BAC、UNH、USDJPY、EURUSD、GBPUSD，所有资产等权。请使用蒙特卡洛方法评估S&P 500下跌5%时该组合的下行风险。

## 用持仓列表构建条件压力测试

示例投资组合包括**20只美股和3个外汇货币对**，共23个等权仓位，每项约 **4.35%**。通过估计市场Beta与残差相关性，在S&P 500假设下跌 **5%** 的情况下运行 **50,000次**模拟。

## 持仓的市场敏感度

![组合23项持仓对应SP500的历史Beta](../../../../assets/usecases/reflexivity/deep-research-2026-10/RX-USECASE-0082-spx-beta-by-asset.png)

*图1：基于2023至2026年日收益率估计的SPX Beta。AMD 2.349、TSLA 2.310、NVIDIA 2.106、Broadcom 2.065的估计敏感度较高。*

## 模拟组合收益分位数

![SP500下跌5百分比条件下投资组合蒙特卡洛收益分位数](../../../../assets/usecases/reflexivity/deep-research-2026-10/RX-USECASE-0082-simulated-portfolio-quantiles.png)

*图2：条件收益的分位数柱状图，不是直方图或连续概率密度。*

| 模拟指标 | 结果 |
| --- | ---: |
| 平均组合收益 | −4.66% |
| 组合对SPX的Beta | 0.93 |
| 95% VaR收益阈值 | −5.16% |
| 99% VaR收益阈值 | −5.37% |
| 损失超过5%的模拟概率 | 13.4% |

这些数值取决于**固定Beta和近似正态的残差**，不能保证实际损失不会超出范围。极端时期可能出现尾部风险、相关性突变和流动性冲击。把股票与USDJPY、EURUSD、GBPUSD简单等权时，还需要明确各外汇仓位的名义金额和本币计价损益方向。
